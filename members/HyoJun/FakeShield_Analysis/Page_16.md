# FakeShield 논문 요약 및 번역 - 16페이지

## 부록 (Appendix)

### A.1 한계점 및 향후 과제 (Limitations and Future Works)
현재 프레임워크의 한계점 중 하나는 **신원 교체(Identity Switching)**나 **전체 얼굴 생성**과 같은 고도로 복잡한 Deepfake 변조를 처리할 때 성능이 다소 떨어진다는 점입니다. 이를 해결하기 위해 다음과 같은 향후 계획을 세우고 있습니다:
1. **사고 사슬(Chain-of-Thought, CoT) 메커니즘 도입**: 모델의 추론 능력을 강화하여 아주 미세한 변조 흔적까지 감지하도록 개선.
2. **학습 데이터셋 확장**: 더 다양한 변조 기법과 시나리오를 포함하는 대규모 샘플을 추가하여 일반화 성능 향상.
3. **모듈 최적화**: 복잡한 변조 유형을 더 잘 다룰 수 있도록 특정 모듈들을 정교하게 튜닝.

### A.2 데이터 소스 (Data Sources)
- **DeepFake 데이터**: `DFFD` 데이터셋의 일부인 `FaceApp`과 `FFHQ`를 활용했습니다. `FFHQ`는 실제 얼굴 이미지, `FaceApp`은 속성이 조작된 가짜 얼굴을 포함합니다.
- **AIGC-Editing 데이터 구축**: `COCO` 데이터셋에서 2만 장의 이미지를 수집하고, `SAM`으로 객체를 분할한 뒤 `Stable-Diffusion-Inpainting`을 사용하여 해당 부분을 다시 그리는 방식으로 변조 데이터를 생성했습니다. 양질의 학습을 위해 긍정/부정 샘플의 균형을 맞췄습니다.

---
**표 7 분석**: 학습 및 평가에 사용된 전체 데이터셋의 통계를 보여줍니다. `Fantastic Reality`, `CASIAv2`, `COCO`, `AIGC-Editing` 등 다양한 출처에서 수만 장의 실제/위조 이미지를 확보하여 실험의 신뢰도를 높였습니다.
