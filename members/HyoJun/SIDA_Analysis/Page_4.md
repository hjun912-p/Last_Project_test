# SIDA 논문 요약 및 번역 - 4페이지

## 3.2 벤치마크 구축 (Benchmark Construction)

### 데이터 세부 정보
소셜 미디어 이미지 탐지 및 위치 식별을 위한 벤치마크를 개발하기 위해 실제(Real), 합성(Synthetic), 변조(Tampered) 이미지를 포함하는 **SID-Set**을 구축했습니다.
- **실제 이미지 (100K)**: 다양한 실제 시나리오를 반영하는 OpenImages V7에서 추출.
- **합성 이미지 (100K)**: 매우 높은 사실성을 제공하는 FLUX 모델을 사용하여 생성.
- **변조 이미지 (100K)**: 특정 객체나 영역을 교체하거나 수정한 이미지.

### 데이터 생성 (Data Generation)
고도로 사실적인 이미지를 생성하기 위해 FLUX, Kandinsky 3.0, SDXL 등 여러 오픈 소스 생성 모델을 테스트했습니다. 5명의 전문가가 각 모델에서 생성된 1,000장의 이미지를 검토한 결과, 인간이 실제와 구분하기 가장 어려운 **FLUX** 모델이 가장 우수한 성능을 보여 기본 생성 모델로 채택되었습니다.

### 이미지 변조 프로세스 (Tampering Process)
그림 3에 묘사된 이미지 변조 과정은 다음과 같은 4단계로 진행됩니다:
- **1단계 (객체 추출)**: GPT-4o를 사용하여 이미지 캡션에서 주요 객체(명사)를 추출합니다. 예를 들어 "나무 테이블 위에 누워 있는 큰 털복숭이 고양이"라는 캡션에서 "고양이"를 추출합니다.
- **2단계 (마스크 생성)**: Language-SAM을 사용하여 식별된 객체에 대한 정교한 마스크를 생성합니다. 이는 학습을 위한 정답(Ground Truth) 데이터로 사용됩니다.
- **3단계 (교체 사전 구축)**: COCO 클래스를 활용하여 객체를 다른 것으로 바꾸거나(예: 개를 고양이로), 속성을 변경(예: 행복한, 화난)하기 위한 사전을 구축합니다.
- **4단계 (이미지 재생성)**: Latent Diffusion 모델을 사용하여 수정된 캡션에 따라 이미지를 재생성합니다.

---
**그림 3 설명**: 캡션 추출(GPT-4o), 마스크 획득(Language-SAM), 교체 사전 설정, 이미지 재생성(Latent Diffusion)으로 이어지는 변조 이미지 생성 파이프라인을 보여줍니다.
**그림 4 설명**: 새(bird)가 독수리(eagle)로 바뀌거나 고양이가 개로 바뀌는 등 정교하게 변조된 이미지의 예시를 보여줍니다.
