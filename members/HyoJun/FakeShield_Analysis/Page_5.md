# FakeShield 논문 요약 및 번역 - 5페이지

## 3.2 FakeShield 전체 프레임워크 (Overall Framework)
두 가지 핵심 과제(M-LLM을 활용한 진위 판단 및 설명을 통한 위치 식별 지원)를 해결하기 위해, 우리는 탐지/해석과 위치 식별을 분리(Decoupled)하여 설계했습니다. 두 작업을 동시에 학습시키면 네트워크 최적화가 어려워지고 서로 간섭이 발생하기 때문입니다.

### 3.3 도메인 태그 가이드 기반 위조 탐지 모듈 (DTE-FDM)
- **동기**: DeepFake는 얼굴 수정에 집중하는 반면, Photoshop은 경계면의 결함이 뚜렷하고, AIGC 편집은 질감 세부 사항이 뭉개지는 등 각 변조 방식마다 특징이 다릅니다. 이 도메인 간의 차이를 완화하기 위해 **도메인 태그 생성기(DTG)**를 도입했습니다.

---
**그림 3 설명**: FakeShield의 파이프라인을 보여줍니다.
1. 입력 이미지($I_{ori}$)는 먼저 **도메인 태그 생성기($G_{dt}$)**를 통해 도메인 태그($T_{tag}$)를 얻습니다.
2. 텍스트 지시문($T_{ins}$), 도메인 태그, 이미지 토큰($T_{img}$)이 함께 학습된 LLM에 입력되어 탐지 결과와 설명($O_{det}$)을 생성합니다.
3. 생성된 설명($O_{det}$)과 이미지 토큰은 **변조 이해 모듈($C_t$)**에 입력됩니다.
4. 마지막 층의 `<SEG>` 토큰 임베딩($h_{<SEG>}$)이 SAM 모델의 프롬프트 역할을 하여 정확한 변조 영역 마스크($M_{loc}$)를 생성합니다.
- **Full Parameter Training**: 완전 학습 부분.
- **LoRA Finetune**: 효율적인 미세 조정 적용 부분.
- **Frozen**: 고정된 부분.
