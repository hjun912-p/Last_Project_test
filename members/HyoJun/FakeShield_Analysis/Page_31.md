# FakeShield 논문 요약 및 번역 - 31페이지

### 그림 20: MMTD-Set 데이터 샘플 예시 (DeepFake 변조 및 실제 이미지)

MMTD-Set에 포함된 안면 조작 관련 데이터 샘플들입니다.

1. **머리카락/귀 조작 (위조)**: 머리 윗부분과 양쪽 귀 영역이 DeepFake로 수정되었습니다. 머리카락의 질감이 균일하지 않고 뭉쳐 보이며, 헤어라인이 두피와 만나는 경계가 실제 사진보다 훨씬 날카롭고 부자연스럽습니다.
2. **턱선/턱 조작 (위조)**: 턱과 입 주변 영역이 조작되었습니다. 조작된 부위의 피부 톤이 주변과 미세하게 일치하지 않으며, 턱의 곡선이 얼굴 뼈 구조와 맞지 않게 지나치게 매끄러운 '인형 같은' 느낌을 줍니다.
3. **실제 인물 사진 1**: 머리카락 한 올 한 올의 자연스러운 비대칭성과 귀 주변의 미세한 솜털, 그리고 피부의 모공 질감이 그대로 살아있는 실제 사례입니다.
4. **실제 인물 사진 2**: 인물의 옷감 주름이 중력 방향으로 자연스럽게 잡혀 있으며, 머리카락에 맺히는 빛망울과 그림자의 조화가 매우 일관된 실제 사례입니다.
