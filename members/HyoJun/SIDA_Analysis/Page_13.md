# SIDA 논문 요약 및 번역 - 13페이지

## 부록: 시각적 사례 (Visual Examples)

### 그림 9: SIDA의 작동 예시
사용자가 대화형 프롬프트를 통해 이미지의 진위 여부를 묻고 변조 부위를 찾아달라고 요청하면, SIDA는 이를 탐지하고 마스크를 생성합니다.

- **프롬프트**: "이 이미지가 실제인지, 전체 합성인지, 변조된 것인지 식별해 주세요. 변조되었다면 해당 부분을 마스크로 표시해 주세요."
- **모델 응답**: "네, 마스크는 다음과 같습니다: `<SEG>`"

**주요 사례 분석**:
- **고양이 이미지**: 고양이의 눈 색깔이 빨간색으로 부자연스럽게 변조된 부분을 정확히 마스크로 식별했습니다.
- **일상 장면**: 해변의 인물, 거리의 자전거, 주방의 물건들이 정교하게 삽입되거나 수정된 부분을 모델이 정확하게 찾아내어 강조합니다.

이 사례들은 SIDA가 미세한 객체 조작부터 색상 변조까지 다양한 소셜 미디어 위조 유형을 효과적으로 처리할 수 있음을 시사합니다.
