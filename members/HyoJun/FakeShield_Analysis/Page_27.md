# FakeShield 논문 요약 및 번역 - 27페이지

### 그림 16: 실제 얼굴 이미지에 대한 대화형 분석 예시

FakeShield가 실제 얼굴 사진을 DeepFake와 구분해내는 구체적인 관점을 보여줍니다.

**사례 분석 공통 항목**:
1. **피부 질감**: 실제 피부에서 나타나는 미세한 톤 변화와 자연스러운 그림자가 빛의 방향과 일치하게 나타납니다.
2. **머리카락의 세밀함**: DeepFake가 흔히 놓치는 머리카락 한 올 한 올의 두께 변화와 불규칙한 흐름이 살아있으며, 헤어라인 주변의 질감이 매우 사실적입니다.
3. **광학적 일치**: 안경을 쓴 경우, 렌즈를 통한 반사와 투명도가 물리 법칙에 어긋나지 않게 표현되어 있습니다.
4. **결함의 자연스러움**: "완벽한 대칭"보다는 실제 인간의 얼굴에서 발견되는 미세한 비대칭과 불완전함이 오히려 '진짜'임을 증명하는 증거로 사용됩니다.

**FakeShield의 코멘트**:
"이 이미지가 DeepFake 위조들 사이에 섞여 있다면, 머리카락의 질감 변화와 피부에 비치는 빛의 사실적인 상호작용, 그리고 인위적인 왜곡이 전혀 없는 깔끔한 경계선이 이 사진이 진짜임을 입증하는 핵심 지표가 될 것입니다."

이 분석은 FakeShield가 **DeepFake 특유의 아티팩트(Artifacts)**를 명확히 인지하고 있기에 가능한 결과입니다.
