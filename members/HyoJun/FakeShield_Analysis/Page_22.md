# FakeShield 논문 요약 및 번역 - 22페이지

### 그림 11: 실제 이미지에 대한 타 모델과 FakeShield의 분석 결과 비교

이 페이지는 변조되지 않은 **실제 사진**(물속에서 돌고래와 수영하는 사람)을 대상으로 모델들의 판단을 시험한 사례입니다.

- **GPT-4o, InternVL, Qwen**: 돌고래의 위치나 조명이 자연스럽지 않다거나 가장자리가 너무 날카롭다는 이유를 들어 **'위조(Fake)'로 오판**했습니다. 이는 일반적인 모델들이 복잡한 환경에서의 자연스러운 시각 현상을 위조의 증거로 오해할 수 있음을 보여줍니다.
- **LLaVA**: "위조의 뚜렷한 징후가 보이지 않으며 실제 사진으로 보인다"고 맞췄으나, 구체적인 기술적 분석 근거는 다소 부족했습니다.
- **FakeShield**: 
  1. **정확한 판단**: 이미지가 변조되지 않은 실제임을 확인했습니다.
  2. **전문적 근거**: 돌고래의 머리가 주변 물과 자연스럽게 통합되어 있으며, 조명과 그림자의 방향이 전체 장면의 광원과 완벽히 일치한다는 점, 신체 비율이 물리적 법칙을 따른다는 점 등을 들어 논리적으로 설명했습니다.

**결론**: FakeShield는 위조를 잡아낼 뿐만 아니라, 실제 이미지를 가짜로 오판하지 않는 높은 **변별력**을 갖추고 있음을 입증합니다.
