# FakeShield 논문 요약 및 번역 - 8페이지

## 4.2 비교 분석 (계속)
- **도메인 태그의 효과**: 도메인 태그 가이드 전략 덕분에 FakeShield는 전통적인 IFDL 벤치마크뿐만 아니라 DeepFake(0.93)와 AIGC 변조(0.98)에서도 탁월한 탐지 정확도를 보여주었습니다. 반면 다른 모델들은 데이터 도메인 간의 충돌을 처리하는 효과적인 메커니즘이 부족하여 성능이 제한적이었습니다. (표 2 참고)

### 4.3 M-LLM과의 비교 (설명 능력)
- **텍스트 품질**: GPT-4o가 생성한 정답 설명을 기준으로 CSS(의미 유사도)를 측정한 결과, FakeShield는 모든 테스트 세트에서 InternVL2나 LLaVA 같은 최신 모델들보다 훨씬 높은 점수를 기록했습니다. (표 3 참고)
- **분석**: 일반적인 M-LLM들은 물리 법칙 위반과 같은 명백한 오류는 잡아내지만, 조명이나 원근감의 미세한 불일치를 정밀하게 분석하는 데는 어려움을 겪어 정확도가 떨어집니다.

---
**그림 4 설명**: FakeShield의 실제 출력 사례입니다.
- **사용자 질문**: "이 이미지가 위조되었나요? 왜 그렇게 생각하는지 설명하고 변조 영역을 알려주세요."
- **FakeShield 응답**: 
  1. **진위 판단**: 위조됨(Fake).
  2. **위치 식별**: 하늘에 떠 있는 3대의 전투기 부위.
  3. **판단 근거**: 
     - 조명(전체 장면과 전투기에 비치는 빛의 각도가 다름), 
     - 가장자리(전투기 주변이 너무 날카로워 자연스럽지 않음), 
     - 해상도(전투기 부분만 픽셀이 깨져 보임), 
     - 물리 법칙(전투기 비행에 따른 연기나 환경 상호작용이 없음) 등을 논리적으로 설명.
  - 정확한 마스크 이미지 제공.
